# Security policy

GitHub private vulnerability reporting is **not enabled** on this repository (checked 2026-10-15).

To report a suspected vulnerability, email redevops@redevops.io (organisation email listed on the GitHub org profile) with a description and reproduction steps. Please do not open a public issue for an undisclosed vulnerability.

Response times, supported-version commitments and a PGP key: contact to be confirmed. Practical guidance: use the latest tag on the `v0.1.x` line (see [STATUS.md](STATUS.md)).
